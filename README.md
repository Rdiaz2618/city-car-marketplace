# city-car-marketplace

Proyecto de interfaz web tipo catálogo de productos, desarrollado con HTML y CSS.

---

## 🚀 Descripción

Layout responsivo con CSS Grid que incluye:
- Navbar
- Filtros
- Tarjetas de productos
- Paginación
- Footer

---

## 🛠️ Tecnologías

- HTML5
- CSS3 (Grid + Flexbox)

---

## 📱 Responsive

- Mobile: 1 columna
- Tablet: 2 columnas
- Desktop: 4 columnas + sidebar

---

## ⚙️ Características

- Layout con `grid-template-areas`
- Scroll interno en productos
- Diseño adaptable a distintos tamaños de pantalla
